## 🎯 프로젝트 소개 (About)

지뢰찾기는 운에 맡기는 게임이 아니라 명확한 논리 추론 게임입니다.  
**Minesweeper 101**은 처음 시작하는 입문자부터 기록 단축을 노리는 플레이어까지 누구나 바로 즐기고 실력을 키울 수 있도록 구성되어 있습니다.

1. **클래식 지뢰찾기 플레이 (`src/`)**: 첫 클릭 안전 보장(First-Click Safe), 깃발 꽂기, 빠른 열기(Chording), 주변 8칸 가이드, 난이도별 최고 기록 저장까지 지원합니다.
2. **실시간 지뢰 찾기 코치 & 5단계 공략 (`PlayerGuidePanel`)**: 막히는 순간 `공략 힌트`를 누르면 `1-1 패턴`, `1-2 패턴`, `확정 지뢰/안전` 등 현재 보드에 적용 가능한 추론 이유를 직접 짚어줍니다.
3. **모바일·PC 완벽 지원**: PC에서는 키보드 방향키/`F`/`H`/`R` 단축키를, 모바일에서는 하단 엄지 조작 바와 길게 눌러 깃발 꽂기(Long-press)를 지원합니다.

### ✨ 주요 플레이 기능
* **첫 클릭 안심 출발**: 처음 클릭한 칸과 주변 8칸(3×3)에는 절대 지뢰가 배치되지 않습니다.
* **실전 공략 힌트 코치**: 단순 정답 표시가 아니라 *"왜 여기가 지뢰(또는 안전)인지"* 패턴과 함께 설명해 줍니다.
* **주변 8칸 가이드**: 열린 숫자에 마우스를 올리면 해당 숫자가 가리키는 8방향 범위를 하이라이트해 입문자도 직관적으로 수를 읽을 수 있습니다.
* **빠른 열기 (Chording)**: 숫자 주변에 지뢰 개수만큼 깃발을 꽂은 뒤 숫자를 클릭하면 나머지 안전 칸을 한 번에 열어줍니다.
* **난이도 프리셋 & 최고 기록**: 초급(9×9, 10개), 중급(16×16, 40개), 고급(30×16, 99개) 지원 및 난이도별 개인 최고 클리어 시간 자동 저장
* **다크 / 라이트 테마 전환**: 눈이 편안한 OLED 다크 모드와 산뜻한 라이트 모드를 즉시 전환할 수 있습니다.

## 🎮 조작 방법 (Controls)

| 환경 | 칸 열기 | 깃발 꽂기 | 빠른 열기 (Chording) |
| :--- | :--- | :--- | :--- |
| **PC (마우스)** | 좌클릭 | 우클릭 (또는 모드 전환) | 열린 숫자 클릭 / 더블클릭 |
| **PC (키보드)** | 방향키 이동 후 `Enter` / `Space` | `F` 키 | 열린 숫자에서 `Enter` / `Space` |
| **모바일 (터치)** | 짧게 탭 | 길게 누르기 (또는 하단 `깃발` 모드) | 열린 숫자 짧게 탭 |

* **단축키**: `H` 공략 힌트 보기 · `R` 새 게임 시작

## 📚 실전 지뢰 찾는 법 5단계 (Player Strategy Guide)

게임 화면 우측(모바일은 `지뢰 찾는 법` 탭)에서 시각적 미니 패턴 보드와 함께 바로 학습할 수 있습니다.

1. **Step 01 · 숫자가 알려주는 비밀**: 숫자 `1~8`은 주변 8칸에 숨어 있는 지뢰의 총 개수입니다.
2. **Step 02 · 찍지 않고 100% 확정 찾기**: `닫힌 칸 수 = 숫자`이면 모두 지뢰, `주변 깃발 수 = 숫자`이면 나머지는 모두 안전합니다.
3. **Step 03 · 가장 많이 쓰는 1-1 패턴**: 벽에 붙은 `1-1`에서 안쪽 1이 지뢰를 품고 있으므로 3번째 바깥 칸은 항상 안전합니다.
4. **Step 04 · 지뢰를 콕 집어내는 1-2 패턴**: 나란히 있는 `1-2`에서 `2`의 바깥쪽 튀어나온 칸은 반드시 지뢰입니다.
5. **Step 05 · 빠른 열기 & 실전 운영 팁**: Chording으로 빠르게 안전 구역을 확장하는 요령과 실수 방지 팁을 익힙니다.

## 🚀 로컬에서 실행하기 (Getting Started)

```bash
# 1. 레포지토리 클론
git clone https://github.com/hcjo1223/minesweeper-101.git

# 2. 프로젝트 폴더로 이동
cd minesweeper-101

# 3. 의존성 패키지 설치
npm install

# 4. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속하여 바로 플레이할 수 있습니다.

### 테스트 및 빌드

```bash
# 코어 엔진 및 추론 힌트 단위 테스트 실행 (Vitest)
npm test

# 프로덕션 빌드 검증
npm run build
```
